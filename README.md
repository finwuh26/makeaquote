# Make a Quote — Discord Bot

An advanced Discord.js v14 slash command bot that generates beautiful, customisable quote images from Discord messages.

---

## Features

| Feature | Description |
|---|---|
| `/quote <message_id>` | Quote any message in the current channel by ID |
| `/customquote <text> <author>` | Create a quote with any text and author name |
| `/randomquote [category]` | Generate an inspirational quote image |
| `/settings user` | Interactive personal settings dashboard |
| `/settings server` | Interactive server-wide settings dashboard (Manage Server required) |
| `/help` | List all commands |
| **Right-click → Apps → Make a Quote** | Instant context menu quoting |
| **Reply + @mention** | Reply to a message and @mention the bot to quote it |
| **Interactive buttons** | Theme, font and layout controls beneath every quote |
| **Quote Redirect** | Auto-forward every quote to a designated channel |

---

## Interactive Settings Dashboard

Run `/settings user` or `/settings server` to open an in-Discord dashboard panel:

- **Theme** – Choose from Dark, Light, Midnight, Ocean, Sunset or Forest
- **Font** – Serif, Sans-serif or Monospace
- **Layout** – Toggle avatar, timestamp and server info independently
- **Accent Colour** – Pick from 8 preset colours
- **Reset** – Restore everything to defaults
- **Redirect Channel** *(server only)* – Select any text channel; every generated quote is automatically forwarded there

All changes take effect immediately and are saved per-user or per-server.

---

## Quote Redirect Channel

Server admins can designate a single channel to aggregate every quote generated on the server:

1. Run `/settings server`
2. Click **📢 Set Redirect Channel**
3. Select the channel from the picker
4. Click **← Back to Settings** when done

Every quote generated by any member (slash command, context menu or @mention reply) will be forwarded to that channel automatically.

## Setup

### 1 — Prerequisites

- Node.js **v18+** (v20 or v22 recommended)
- A Discord application with a bot token ([Discord Developer Portal](https://discord.com/developers/applications))
- Bot must have the **Message Content** privileged intent enabled

### 2 — Installation

```bash
git clone https://github.com/finwuh26/makeaquote.git
cd makeaquote
npm install
```

### 3 — Configuration

```bash
cp .env.example .env
```

Edit `.env`:

```env
DISCORD_TOKEN=your_bot_token_here
CLIENT_ID=your_application_client_id_here

# Optional: set for guild-only deployment during development (instant)
GUILD_ID=

# Optional: https://api-ninjas.com/ free tier key for /randomquote categories
QUOTES_API_KEY=
```

### 4 — Deploy commands

```bash
# Global (up to 1 hour to propagate):
npm run deploy

# Specific guild only (instant, good for testing):
GUILD_ID=123456789012345678 npm run deploy:guild
```

### 5 — Start the bot

```bash
npm start
```
